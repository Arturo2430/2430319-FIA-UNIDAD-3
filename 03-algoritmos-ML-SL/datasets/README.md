# Datos de apoyo: Iris

Esta carpeta conserva `Iris.csv` como material de datos de la unidad. Iris es un conjunto utilizado para estudiar clasificación de especies a partir de medidas de flores.

El notebook de árboles y Random Forest de esta entrega carga Iris directamente mediante `sklearn.datasets.load_iris()`. El notebook KNN genera un conjunto sintético mediante `make_blobs`. Por tanto, ninguno de los dos necesita leer este CSV para ejecutarse.

El archivo se mantiene disponible para consulta y otros ejercicios. Puede abrirse con un editor de texto, una hoja de cálculo o una biblioteca de análisis de datos.
