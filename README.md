## Trabajo de la unidad

Las actividades reúnen un proyecto de búsqueda de ciclos hamiltonianos, la recopilación y preparación de un catálogo de anime y prácticas de aprendizaje automático supervisado. El material permite estudiar tanto la búsqueda de soluciones mediante metaheurísticas como la preparación de datos y la clasificación a partir de ejemplos etiquetados.

El proyecto FHCP conserva su documentación, código, experimentos y entregables originales. El crawler consulta la API de Kitsu, almacena el avance en SQLite y traduce las sinopsis localmente para exportar un catálogo en español. Las prácticas supervisadas incluyen KNN, árboles de decisión, Random Forest y el seguimiento del aprendizaje de un perceptrón.
